# 🎯 My Goal

## The Big Picture

I am building expertise as a **data analyst**.

This second brain exists to capture, organize, and reinforce everything I learn along the way — so I can recall it faster, apply it more confidently, and track my growth over time.

## The 4 Pillars

### 🗄️ SQL for Data Analysis
Query and retrieve data directly from relational databases.  
SQL is the foundation — it feeds data into every other tool.  
→ See [[02_sql/What is SQL]]

### 🐍 Python for Data Analysis
Automate, clean, transform, and analyze data programmatically.  
Python gives me the flexibility to go beyond what any single tool can do.  
→ See [[01_python/pandas_read_csv]]

### 📊 Excel for Data Analysis
Fast, accessible analysis and reporting.  
Excel remains one of the most widely used tools in business analytics.

### 📈 Power BI for Data Analysis
Build interactive dashboards and visual reports.  
Power BI is where data becomes a story that non-technical stakeholders can read.

- I can go **directly to the data source** instead of waiting for someone else
- I can **clean and transform** messy data without frustration
- I can **build dashboards** that actually help people make decisions
- I can **communicate insights** clearly, not just technically
