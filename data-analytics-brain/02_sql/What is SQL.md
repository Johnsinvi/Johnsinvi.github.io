## What is it?
SQL (Structured Query Language) is a programming language 
designed specifically to manage data in relational databases.

Unlike general programming languages like Python, SQL has 
one focused purpose — talking to databases.

---

## What is SQL mainly used for?
- **Storing** — saving data into a database
- **Retrieving** — asking the database to return specific data
- **Analyzing** — transforming and summarizing data to find insights

---

## Why SQL matters for data analytics
All the tools I am learning — Excel, Power BI, Python — 
can connect to databases. SQL is the universal language 
that feeds data into all of them.

A data analyst who knows SQL can go directly to the 
source of the data instead of waiting for someone 
else to extract it.

---

## My analogy
A relational database is like a building with many rooms 
(tables). SQL is the key that lets you enter any room, 
look around, and bring back exactly what you need.

---

## Common mistakes to watch for
- SQL is NOT a general programming language like Python
- SQL does NOT build dashboards or charts — 
  that's what Power BI and Python are for
- SQL manages and retrieves data — other tools visualize it
