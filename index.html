US Mineral Production & Import Dependence

An interactive report on US mineral production and the country's reliance on imported critical minerals, built on USGS data. The TMDL model and PBIR report were authored as code (Python and DAX). Highlights: the US is 100% import-reliant on 16 commodities, and China leads world supply for 20 of 39 critical minerals.

US Bank Health Scorecard

A quarterly health scorecard for the 20 largest US banks, built as one reproducible Python pipeline on public FDIC data. A single run produces both this interactive dashboard (pandas and Plotly) and a styled Excel scorecard - Python automating Excel, not replacing it. It tracks six core banking KPIs; the 2020 credit shock and the 2022-23 rate cycle both show up clearly in the trends.

US Oil & Gas Production by State

An interactive dashboard built entirely in native Excel on EIA production data (2000-2026): Power Query ETL, a Power Pivot data model with DAX measures, and slicer-driven charts with linked KPI cards - the full BI stack inside one workbook, no add-ins. Texas alone accounts for 42% of state-level US crude output.
